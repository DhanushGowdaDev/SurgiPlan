# SurgiPlan

AI-Powered Operating Room Scheduling & Resource Optimization.

> Optimize every operating room. Adapt to every change.

## Tech Stack

- React + TypeScript
- Tailwind CSS
- Python FastAPI
- Google OR-Tools CP-SAT
- Gemma
- MongoDB Atlas
- Recharts

## Project Status

🚧 MVP under development

## Core Principle

OR-Tools is the source of truth for scheduling.

Gemma is used for natural-language understanding,
schedule explanations, and what-if scenario interpretation.

## Disclaimer

SurgiPlan is an operations scheduling and resource optimization
prototype. It does not provide medical diagnosis, treatment
recommendations, or clinical decisions.
